# O9 Structural Analyzer

تطبيق ويب تجريبي لتحليل عتبة باستخدام React وVite.

## التشغيل على الكمبيوتر
1. ثبّت Node.js (الإصدار LTS).
2. فك ضغط المشروع.
3. افتح الطرفية داخل مجلد المشروع وشغّل:
   ```bash
   npm install
   npm run dev
   ```
4. افتح الرابط الذي يظهر في الطرفية.

## إنشاء نسخة للنشر
```bash
npm run build
```
سيتم إنشاء مجلد `dist` ويمكن نشر محتوياته على خدمة استضافة مواقع ثابتة مثل Netlify أو Vercel.

## تنبيهات هندسية مهمة
- المحرك يستخدم نموذج Euler–Bernoulli للعناصر المحددة مع EI ثابت.
- المساند المفصلية والبكرية تمنع الإزاحة الرأسية، والثابت يمنع الإزاحة والدوران.
- الأحمال الموزعة والمثلثية والنقطية مدخلة باتجاه الأسفل كقيم موجبة.
- هذا إصدار أولي تعليمي وليس برنامج تصميم معتمد. يجب التحقق المستقل من النتائج، خصوصاً عند وجود مساند ثابتة أو أحمال/قيود غير اعتيادية.
- لا يحسب التصميم الخرساني أو التسليح أو الهبوط المسموح.
